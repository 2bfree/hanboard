# HanBoard City Series — Brand assets

BeFRee Project · HanBoard

## City Series icon concept

도시별 풍경과 색감, 흰색 한글 자모 `ㅎ`, 하단 크림색 도시명 띠를 공통 디자인으로 사용합니다. 하단에는 **도시 이름만** 표시합니다. 국기, 키캡, HANBOARD 문구는 기본 아이콘 안에 추가하지 않습니다.

## 선택한 도시 시리즈

| 도시명 | 대상 언어 | 디자인 배경 | 상태 |
| --- | --- | --- | --- |
| TOKYO | 일본어 | 후지산과 도쿄 타워 | 첫 번째 개발 대상 |
| BEIJING | 표준 중국어 | 천단 | 확장 연구 후보 |
| BANGKOK | 태국어 | 왓 아룬을 모티프로 한 사원 | 확장 연구 후보 |
| DELHI | 힌디어 | 인디아 게이트 | 확장 연구 후보 |
| DHAKA | 벵골어 | 랄바그 요새를 모티프로 한 건축물 | 확장 연구 후보 |
| CHENNAI | 타밀어 | 남인도 사원 고푸람 | 확장 연구 후보 |

영어·프랑스어·베트남어 등 라틴 문자 기반 언어는 현재 범위에서 제외합니다. 비라틴 문자 체계를 사용하는 언어 중 기존 로마자 기반 발음 입력 방식의 대안이 될 가능성이 있는 언어를 연구합니다. 일본어 외의 언어는 출시가 확정되지 않았습니다.

## 이미지 파일

최종 선택한 6개 도시 콘셉트 이미지의 등록 예정 경로는 `assets/hanboard-city-series.png`입니다. PNG 원본은 아직 이 저장소에 업로드되지 않았습니다. 등록 후 메인 README에 이미지를 표시합니다.

현재 디자인은 AI로 생성한 연구·브랜딩 콘셉트이며, 실제 랜드마크 사진이나 출시용 앱 아이콘이 아닙니다. 앱 아이콘 규격, 작은 크기의 가독성, 브랜드 및 이미지 사용 정책은 출시 전에 검토합니다.
