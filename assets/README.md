# HanBoard City Series — Brand assets

BeFRee Project · HanBoard

## City Series icon concept

도시별 풍경과 색감, 흰색 한글 자모 `ㅎ`, 하단 크림색 도시명 띠를 공통 디자인으로 사용합니다. 하단에는 **도시 이름만** 표시합니다. 국기, 키캡, HANBOARD 문구는 기본 아이콘 안에 추가하지 않습니다.

- Tokyo · London · Paris · Beijing · Bangkok · Hanoi
- 첫 번째 연구·개발 대상: Tokyo
- 나머지 도시는 향후 확장 후보

최종 선택한 콘셉트 이미지의 예정 경로는 `assets/hanboard-city-series.png`입니다. 원본 이미지는 아직 이 저장소에 등록되지 않았습니다. 등록 후 메인 README에 이미지를 표시합니다.

현재 디자인은 연구·브랜딩 콘셉트이며, 출시용 앱 아이콘이 아닙니다. 앱 아이콘 규격, 작은 크기의 가독성, 브랜드 및 이미지 사용 정책은 출시 전에 검토합니다.
